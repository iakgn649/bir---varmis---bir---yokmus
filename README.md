Proje hakkında

Bu proje, sekiz Türk masalını tek bir web sayfasında sunan bir masal derlemesidir. HTML, içsel CSS ve JavaScript kullanılarak hazırlanmıştır.

Özellikler
•⁠  ⁠Listeden masal seçme
•⁠  ⁠Masal adına göre arama
•⁠  ⁠Rastgele masal seçme
•⁠  ⁠Yazı boyutunu büyütme ve küçültme
•⁠  ⁠Gece ve gündüz modu
•⁠  ⁠Ekran genişliğine göre değişen sayfa düzeni
•⁠  ⁠İnternetsiz çalışma
Çalıştırma

Depoyu Code → Download ZIP seçeneğiyle indirin ve ZIP dosyasını açın. İçindeki HTML dosyasına çift tıklayarak tarayıcıda açın. Kurulum gerektirmez.

Test

Mac bilgisayarda Google Chrome ile kontrol edilmiştir. Dar ekran düzeni, tarayıcı penceresi küçültülerek denenmiştir. 

Kaynaklar ve yapay zekâ kullanımı

Masal kaynakları proje raporunun kaynakça bölümünde belirtilmiştir. Masalların kısaltılması ve yeniden anlatılması, kodların hazırlanmasında yardım  ve hataların düzeltilmesinde ChatGPT desteği alınmıştır. Tasarım tercihleri tarafımdan belirlenmiş ve özellikler adım adım kontrol edilmiştir.
